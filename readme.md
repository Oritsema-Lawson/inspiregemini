# inspiregemini

This is `inspiregemini`, a personal project I'm working on to practice and learn a few key things:

* **JavaScript (JS):** Getting more comfortable with the language and its uses.
* **Git Workflow & CLI:** Practicing how to use Git properly for tracking changes and working on projects from the command line.
* **HTML & CSS:** Building user interfaces and making them look decent.
* **Electron:** Learning how to turn web skills (HTML, CSS, JS) into a desktop application.

### What it Does

The idea is simple: create a desktop app where you can:

1.  Pick an image from your computer.
2.  Choose a theme.
3.  Send that info to Google's Gemini API to get an inspirational quote.
4.  Take that quote and add it to the image using HTML Canvas.
5.  Preview the final image.
6.  Let you save the picture to your computer.

### Completed

* Picking images and themes.
* Getting quotes from the Gemini API.
* Putting the quote on the image (with Canvas).
* Showing a preview.
